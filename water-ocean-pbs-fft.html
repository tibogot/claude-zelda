Ocean PBS + FFT

FFT 64² ×2 + Gerstner swells. Foam is three fragment layers (whitecaps + ambient + horizon / wake near the box) with hash noise so it does not band like vertex masks. Buoy: height is sampled on the CPU with the same combinedHeight() as the waves (FFT + Gerstner) — it matches what the GPU draws but is not a GPU compute readback. Eight hull points + slope sampling drive bobbing, pitch, and roll. No SSR in this demo; env reflections are IBL only.
